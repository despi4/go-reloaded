# Goreloaded

Goreloaded — это инструмент автокоррекции текста, написанный на языке Go. Он принимает входной текстовый файл, анализирует и преобразует его содержимое в соответствии с определёнными правилами (флаги и пунктуация), и сохраняет результат в выходной файл.

## 📋 Описание задания

Программа должна читать файл, находить специальные конструкции и изменять текст в соответствии с заданными правилами. Ниже перечислены все поддерживаемые модификации.

## ✨ Функциональность

🔤 **Флаги преобразования текста:**

| Флаг          | Описание |
|---------------|----------|
| `(low)`       | Преобразует **одно** предыдущее слово в нижний регистр |
| `(low, N)`    | Преобразует **N** предыдущих слов в нижний регистр |
| `(up)`        | Преобразует **одно** предыдущее слово в верхний регистр |
| `(up, N)`     | Преобразует **N** предыдущих слов в верхний регистр |
| `(cap)`       | Делает заглавной первую букву **одного** предыдущего слова |
| `(cap, N)`    | Делает заглавными первые буквы **N** предыдущих слов |

🔢 **Числовые флаги:**

| Флаг         | Описание |
|--------------|----------|
| `(hex)`      | Преобразует **предыдущее слово** из 16-ричного числа в десятичное |
| `(bin)`      | Преобразует **предыдущее слово** из 2-чного числа в десятичное |

🔠 **Грамматические правила:**

- `a` → `an`, если **следующее слово начинается с гласной** (`a, e, i, o, u, h`).
- `' ... '` → Склеивает кавычки с содержимым: `' awesome '` → `'awesome'`. Поддерживает много слов между кавычками.
- `.,!?;:` → Всегда **без пробела перед** и **с пробелом после**, кроме:  
  - многоточие (`...`)  
  - конструкции вроде `!?`, `!!`, и т.д. — **оставляются как есть, без пробелов**
